# Movie Watchlist

*Group:* Software67
*Topic:* Movie Watchlist
*Members:* Kenzo, Alvaro, Russell, Jan

## Product Backlog

1. **As a user, I can add a movie to my watchlist, so that I can keep track of movies I want to watch.**
   Each movie is stored with its title, genre, mood, running time, director and three main actors.

2. **As a user, I can rate a movie, so that I can keep my personal opinion of the movies in my watchlist.**
   Each movie can have a personal rating that is saved with it.

3. **As a user, I can get a suggestion of what to watch next, so that I do not have to choose manually from my whole watchlist.**
   The suggestion uses the information stored about the movies and the filters selected by the user.

4. **As a user, I can filter movies by mood, so that I can find something that fits what I feel like watching.**

5. **As a user, I can filter movies by running time, so that I can choose a movie that fits the time I have available.**

6. **As a user, I can filter movies by genre, so that I can find the type of movie I want to watch.**

7. **As a user, I can filter movies by one of the three main actors, so that I can find movies featuring an actor I want to watch.**

8. **As a user, I can filter movies by director, so that I can find movies made by a director I am interested in.**

9. **As a user, I can combine filters, so that I can narrow the watchlist to movies that match several preferences at once.**
